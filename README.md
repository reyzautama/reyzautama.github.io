# Portofolio — Landing Page 1 Halaman

File tunggal `index.html` (tanpa build, tanpa dependensi). Langsung bisa dibuka
di browser dengan dobel-klik.

## Yang perlu diganti sebelum dipakai

Cari-ganti di `index.html`:

| Cari | Ganti dengan |
|------|--------------|
| `Nama Anda` / `Nama<span>Anda</span>` | Nama/brand Anda |
| `62XXXXXXXXXXX` (2 tempat, link wa.me) | Nomor WA Anda format internasional, contoh `6281234567890` |
| `email@anda.com` | Email Anda |

Harga di kartu layanan (Rp 500rb–1jt) = harga perdana untuk 3 klien pertama.
Naikkan setelah ada review.

## Deploy gratis (pilih salah satu)

**Netlify (paling cepat):**
1. Buka https://app.netlify.com/drop
2. Seret folder `portofolio/` ke halaman itu
3. Dapat link publik → pakai di proposal/profil freelance

**GitHub Pages:**
1. Buat repo baru → unggah `index.html`
2. Settings → Pages → branch `main` / root
3. Dapat link `https://username.github.io/repo/`

**Vercel:** `npx vercel` di folder ini, ikuti prompt.
